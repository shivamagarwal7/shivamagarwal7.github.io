AI agents and coding workflows

A reading path through Shivam Agarwal’s writing on agent memory, Claude Code, test-driven development, and retrieval-augmented generation.

Curated by Shivam Agarwal

This collection brings together my writing on AI agents: how they use context and memory, how coding agents fit into development workflows, and how retrieval connects AI with information. The linked writing pages contain short introductions; the complete articles are on Medium.

Where should I start?

  • Retrieval and context: start with RAG: Giving Your AI a Library Card.
  • Agent internals: explore OpenClaw’s memory architecture and the Pi coding agent.
  • Development workflows: read about TDD pair programming with Claude Code and Git-native task tracking for agents.

Is there code to explore?

The Claude Code × TDD project links to an example Python authentication service built around test-driven pair programming. It includes email/password registration, bcrypt password hashing, and in-memory or PostgreSQL storage options.

For the retrieval side of AI systems, explore search and Elasticsearch. For my professional background, see technology strategy and engineering work.
