This little corner of the internet

A personal home for writing, projects, and tributes.

A personal website should be a place to return to. This one brings writing, projects, and a professional profile together in a quiet, readable space.

Built around the words

Warm paper tones, simple typography, generous spacing, and a quiet green accent. Articles have a narrow reading column. The notebook is searchable, and every new Markdown post joins the archive and RSS feed automatically.

A small footprint

Hugo generates plain HTML, CSS, and a little JavaScript. Markdown files hold the content. The publishing setup is designed for a Git push to trigger a new build on Cloudflare Pages. Connecting the hosting account is the remaining deployment step.
